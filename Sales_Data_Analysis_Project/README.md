# Sales Data Analysis using Python & SQL

## Project Overview
This beginner-friendly Data Analyst project analyzes a synthetic retail sales dataset containing 250 orders from January to August 2026.

## Tools Used
- Python
- Pandas
- Matplotlib
- MySQL
- GitHub

## Business Questions
1. What are total sales and profit?
2. Which products generate the most revenue?
3. Which cities generate the most sales?
4. What is the monthly sales trend?
5. Which customers are the top buyers?
6. Which categories have the best profit margin?

## How to Run
### Python
Open a terminal in the `python` folder and run:
`python sales_analysis.py`

### SQL
1. Open MySQL Workbench.
2. Run `sql/sales_analysis.sql`.
3. Import `data/sales_data.csv` into the `sales_data` table using the MySQL Workbench import wizard.
4. Run the analysis queries.

## Key Skills Demonstrated
- Data cleaning
- Exploratory Data Analysis (EDA)
- GroupBy and aggregation
- SQL GROUP BY, HAVING, ORDER BY, LIMIT
- SQL CTE and window function
- Data visualization
- Business insights
